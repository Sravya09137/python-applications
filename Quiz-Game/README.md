# Quiz Game

A command-line quiz application built with Python that allows users to choose a quiz category, answer questions, and receive a final score.

## Features

* Interactive command-line interface
* Three quiz categories:

  * General Knowledge
  * Science Facts
  * Movies and TV Shows
* Three questions per category
* Automatic answer validation
* Score tracking
* Input-based category selection

## How It Works

1. The application welcomes the user and asks whether they want to play.
2. The user selects a quiz category.
3. The application presents three questions from the selected category.
4. Each answer is checked against the expected answer.
5. The score is updated for every correct answer.
6. The final score is displayed at the end of the quiz.
