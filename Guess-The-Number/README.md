# Guess The Number

A command-line Python game where the user tries to guess a randomly generated number within a chosen range.

## Features

* Interactive command-line interface
* User-defined guessing range
* Random number generation
* Higher/lower hints after each guess
* Input validation
* Tracks the number of guesses
* Displays the correct number and total guesses when the user wins

## How It Works

1. The application asks the user whether they want to play.
2. The user enters a range for the guessing game.
3. A random number is generated between 1 and the selected range.
4. The user repeatedly enters guesses.
5. The application provides a hint to guess higher or lower when the guess is incorrect.
6. The game continues until the correct number is guessed.
7. The total number of guesses is displayed.
