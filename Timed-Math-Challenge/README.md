# Timed Math Challenge

A command-line Python application that challenges users to solve arithmetic problems as quickly as possible while tracking the total time taken.

## Features

* Generates random arithmetic problems
* Supports addition, subtraction, and multiplication
* Provides 10 problems per challenge
* Allows repeated attempts until the current problem is answered correctly
* Tracks incorrect attempts
* Measures the total time taken to complete the challenge
* Displays the final result and completion time

## How It Works

1. The application displays a welcome message and waits for the user to start.
2. Random arithmetic problems are generated using numbers within a defined range.
3. The user enters an answer for each problem.
4. If the answer is incorrect, the user can retry the current problem.
5. The application records the total time taken to complete the challenge.
6. The final result and completion time are displayed.
