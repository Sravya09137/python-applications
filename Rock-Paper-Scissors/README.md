# Rock Paper Scissors

A command-line Python implementation of the classic Rock-Paper-Scissors game where the user plays against a randomly generated computer choice.

## Features

* Interactive command-line gameplay
* Rock, Paper, and Scissors choices
* Random computer selection
* Input validation
* Win, loss, and draw detection
* Tracks user and computer scores
* Option to quit the game at any time

## How It Works

1. The user selects Rock, Paper, or Scissors.
2. The computer randomly selects one of the three choices.
3. The application compares both choices to determine the result.
4. The winner's score is increased.
5. The game continues until the user chooses Q to quit.
6. Final scores for the user and computer are displayed.

```bash
python Rock_Paper_Scissors.py
```
